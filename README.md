# Уголок потребителя «ВолгоРост»

Адаптивный статический сайт для публикации на GitHub Pages. Сервер, сборка и внешние зависимости не нужны.

## Локальный просмотр

Из корня проекта запустите простой HTTP-сервер:

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000`. Открытие `index.html` напрямую также возможно, но локальный сервер точнее воспроизводит работу GitHub Pages.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите в него содержимое проекта.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Выберите ветку `main` (или рабочую ветку) и папку `/ (root)`, затем нажмите **Save**.
5. Дождитесь публикации. Адрес появится в том же разделе. Все пути относительные, поэтому сайт работает и в подпапке вида `username.github.io/repository/`.

Файл `.nojekyll` просит GitHub Pages публиковать файлы без обработки Jekyll.

## Изменение сведений

Все изменяемые сведения находятся в [`js/config.js`](js/config.js):

- блок `seller` — наименование, адреса, реквизиты и контакты;
- блок `schedule` — часы и часовой пояс;
- `emergencyPhones` и `authorityPhones` — телефоны;
- `documents` — карточки и пути документов.

Редактируйте значения справа от двоеточия, не удаляя кавычки и запятые. Для телефона поле `number` отвечает за видимый текст, а `tel` — за номер набора в международном формате.

## Добавление и замена документов

Исходные вложения не были доступны при создании проекта, поэтому поддельные документы не добавлялись.

1. Поместите оригинал ИНН в `assets/documents/ИНН Куприянова.jpg`.
2. Поместите исходный трёхстраничный ЕГРИП в `assets/documents/ЕГРИП.pdf`.
3. При наличии уведомления поместите его в `assets/documents/Уведомление.pdf`.
4. В `js/config.js` у нужной записи замените `available: false` на `available: true`.
5. Не оптимизируйте документ с потерей качества, не обрезайте реквизиты и не накладывайте текст. При замене сохраняйте точное имя и формат либо обновите поле `path`.

PDF открывается во встроенном полноэкранном просмотрщике браузера; рядом всегда доступны скачивание и открытие в новой вкладке. Возможности масштабирования предоставляет браузер. Изображение ИНН показывается целиком и масштабируется по ширине экрана.

## Проверка перед публикацией

- откройте все четыре раздела с телефона и компьютера;
- проверьте кнопки звонка и электронной почты на телефоне;
- откройте, увеличьте и скачайте каждый добавленный документ;
- проверьте консоль браузера на отсутствие ошибок;
- убедитесь, что статус работы соответствует времени Волгограда;
- проверьте интерфейс при ширине 320 px и навигацию клавишей Tab.
