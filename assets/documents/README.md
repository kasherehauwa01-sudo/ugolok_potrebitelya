# Файлы документов

Поместите в эту папку оригиналы с точными именами:

- `ИНН Куприянова.jpg` — оригинальное изображение ИНН;
- `ЕГРИП.pdf` — исходный трёхстраничный PDF;
- `Уведомление.pdf` — уведомление, если оно будет опубликовано.

После добавления файла установите `available: true` у соответствующего документа в `js/config.js`. Не изменяйте, не обрезайте и не дополняйте изображения документов.
